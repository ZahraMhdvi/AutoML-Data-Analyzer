# GuidML – A Guided Low-Code AutoML Framework for Tabular Classification and Clustering

A low-code web application for non-expert users: upload an Excel/CSV dataset, get an
explainable recommendation of the analysis type (classification or clustering), resolve
the target (observed, user-selected or LLM-assisted pseudo-target), rank compatible
algorithms with a bounded Compatibility Score, and inspect results in a fully bilingual
(English / Persian) dashboard. Every dataset is a **project** with cumulative **versions**.

## Run

```bash
python -m venv .venv
.venv\Scripts\activate            # Windows
# source .venv/bin/activate       # macOS / Linux
pip install -r requirements.txt
cp .env .env              # optional: add OPENROUTER_API_KEY for LLM pseudo-targets
python run.py                     # http://127.0.0.1:8000  (API docs: /docs)
```

Language: use the **EN / فا** switch in the header. The choice is stored in the browser
and on the user account (`PATCH /api/auth/me/preferences`).

## What changed in this version (scientific-validity refactoring)

| Area | Implementation |
|---|---|
| Leakage-free classification | `ml_engine/model_execution/runner.py` splits **raw** rows first (per version batch, seeded, stratified); `preprocessing/pipeline.py` is a scikit-learn transformer fitted on the training split only (column selection, median/mode imputation, frozen one-hot vocabulary with unseen-category handling, scaling). No global outlier row removal (`outlier_detector.py`: `none` or train-fitted `clip`). CV refits the whole pipeline inside each fold. |
| Target provenance | Target origin `observed` / `user_selected` / `pseudo` stored in config, results, dashboards and exports. |
| Pseudo-targets | `ml_engine/ai/target_generator.py`: deterministic rule (weighted mean of training ECDF ranks → training quantile cut-offs), fitted on version-1 training rows, persisted with all parameters, frozen for later versions; label-drift diagnostic; circularity ablation (condition A/B), reconstructability R, normalised entropy H. |
| LLM service | `ml_engine/ai/llm_target_service.py`: per-request configuration (key rotation works), error taxonomy (AUTH_ERROR, RATE_LIMIT, TIMEOUT, CONNECTION_ERROR, MODEL_UNAVAILABLE, INVALID_RESPONSE, INVALID_COLUMNS), model failover, call record (request_id, requested/actual method, requested/successful model, fallback flag/reason, latency, status) persisted in `llm_calls`, key scrubbing, privacy-preserving prompt (aggregates only), `GET /api/health/llm`, fallback policy `notify` or `abort`. |
| Compatibility Score | Single canonical path `model_selection/scoring/algorithm_scorer.py`: `CS = clip(50 + 50·raw/R, 0, 100)`, documented weights, hard eligibility filtering (`algorithm_registry.eligibility`), coded rationale. |
| Clustering | Silhouette, Davies–Bouldin, Calinski–Harabasz on non-noise points, noise ratio, bootstrap stability, ARI/NMI (reporting only), edge-case warnings, dynamic profiles; no hard-coded column names. |
| Task recommendation | Deterministic statuses: recommended / potentially_suitable / not_suitable with evidence codes. |
| Validation | `ml_engine/validation.py`: small data, constants, high-null, mixed types, inf, high cardinality, duplicates, imbalance, single-sample classes, schema changes — coded issues, never crashes. |
| Audit | Provenance record per version; `GET /api/projects/{id}/versions/{n}/audit?format=json|csv`. |
| API contract | Errors are `{"detail": {"code", "message", "params"}}`; the UI translates codes. |
| Localization | `frontend/i18n/en-US.json`, `fa-IR.json` (generated by `tools/build_i18n.py`), RTL/LTR switching, Gregorian/Persian dates, mirrored charts. |

Legacy upload-based endpoints and the unused parallel scoring/question modules were removed;
the Django prototype in `backend/` is not used by the application.

## Tests

```bash
python -m pytest -q          # 50 tests: leakage, pseudo-targets, LLM contract (mocked), scoring, clustering, validation, API
```

## Experiments (paper)

```bash
python experiments/prepare_datasets.py                 # downloads public datasets to experiments/data
python experiments/run_benchmarks.py                   # E1 classification, E2 selector, E3 clustering, E4 pseudo-target
python experiments/leakage_comparison.py --original <checkout of the previous version>   # E5
python experiments/llm_reliability.py --data experiments/data/clean   # E6, needs OPENROUTER_API_KEY + network
python experiments/ui_walkthrough.py                   # screenshots (server running, playwright installed)
```

Results used in the paper are in `experiments/results/`; figures and screenshots in `docs/`.

## Data storage

`storage/app.db` (users, projects, versions, results, LLM call log) and
`storage/projects/<id>/batch_<n>.*`. Existing databases are migrated automatically.
Set `APP_DATA_DIR` to store data elsewhere.
